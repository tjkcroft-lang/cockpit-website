# COCKPIT pre-launch website

Static website for COCKPIT, designed to deploy via Cloudflare Pages from GitHub.

## Deployment
Connect this GitHub repository to Cloudflare Pages. Use framework preset **None**, leave build command blank, and set output directory to `/`.

## Before public launch
- Replace both temporary `mailto:` calls to action with working, consent-based email signup forms (e.g. a mailing-list provider's hosted forms). Do not collect emails in client-side JavaScript without a secure service.
- Activate the brand email address before using it as a contact address.
- Add a privacy policy identifying the business, data collected, purpose, provider, and unsubscribe process.
- Verify all product claims and imagery against final production samples.
- Confirm Instagram handle and domain DNS.
- Do not accept payments through this static site. Use a hosted commerce platform when launching sales.
